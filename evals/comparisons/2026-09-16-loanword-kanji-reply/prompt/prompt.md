日本語で書かれたとある Agent Skill の SKILL.md に、以下を参考にして「外部ツールの使用ルール」というセクションを書き加えてください。読み手は日本のソフトウェアエンジニアです。ファイルを作らず、本文を回答に書いてください。

セクションの構成は次のとおりにしてください。

1. 冒頭に索引の表を置く。列は「ID」「名前」「要約」で、名前は 2 文字から 8 文字、要約は 20 文字以内にする
2. ルールごとに、見出し、方針、理由、例を書く。見出しは 12 文字以内にする
3. 例は表にし、列見出しと項目名は短くする
4. セクションの末尾に、このセクションで使う用語を「用語 — 意味」の形で箇条書きにする

ルールの内容:
- 外部ツールを取り込むときは、最新の公開物ではなく、検証済みの特定の公開物に固定する
- 取り込んだ公開物は、配布元が示す `sha256` の値と一致するかを確かめてから使う
- 取り込んだ公開物は、ログインしている利用者に割り当てられたディレクトリの直下に保存しておき、二度目以降はそれを再利用する
- 時間のかかる処理は、端末を占有しない形で動かし、終わったら結果を報告する
- 処理が消費する CPU、メモリ、ディスクの量には上限を設け、上限に近づいたら依頼者に知らせる
- 新しい公開物に切り替えて問題が起きたら、直前に使っていた公開物に戻す
- ツールを選ぶときは、候補ごとに得られるものと失うものを並べて比べる
- ツールに不具合を見つけたら、そのツールを保守している人に、再現手順を添えて報告する
